No teacher participates in student inference. All student parameters remain
trainable. Warm-start each model's recorded best bounded checkpoint; verify

Average learned parameters along this single training continuation, requiring

caps/floors. This is one model at inference, not an ensemble of predictions.

Targeted two-layer classifier fit, added after both continuations failed
---------------------------------------------------------------------
Both 2,000-step continuations retained the original 736/872 parent;
no newly trained checkpoint improved it. Test a deterministic convex
classifier subproblem on frozen parent training features, with no bias or
architecture change. Optimize the class-logit difference with full-batch
float64 LBFGS(max_iter=100). Mix gold CE and gated teacher KL, plus a squared
training-logit-margin penalty toward the parent. Candidate order: root
mixture fraction [.5, 1, 0], teacher coefficient [.5, 0], functional trust
coefficient [10, 1, .1, .01, 0], nested in that order. Validation selects among
these 30 predeclared candidates; stop at first recovery. No validation
features/labels enter the solver. Save every evaluated candidate and its
actual full-model predictions; require the backbone to match the parent
bitwise. Identifier701 denotes this deterministic fit, not a random seed
search. All previous attempts remain.

Reproduction entry points
------------------------
Run from the repository root with .venv/bin/python and PYTHONPATH=src:.
Mistral additionally requires bitsandbytes 0.50.2; this execution used
PYTHONPATH=/tmp/qft-fullft-deps:src:. The pinned student/data assets are at
/tmp/qft-recovery-search-assets. Their assets.json contains source hashes.
The teacher's pinned local files are at /tmp/qft-sst2-teacher-assets, and
the persisted training-logit cache is results/reviewer/recovery_teacher.
Use a fresh output directory for any reproduction; retain the recorded runs.

Teacher preparation (only training logits are cached):
  experiments/runners/prepare_recovery_teacher.py
    --teacher-assets /tmp/qft-sst2-teacher-assets
    --assets /tmp/qft-recovery-search-assets
    --output NEW_TEACHER_OUTPUT --device cuda:0

Continuation runner:
  experiments/runners/reviewer_recovery_guided.py
    --config experiments/configs/reviewer/CONFIG.json
    --assets /tmp/qft-recovery-search-assets
    --teacher results/reviewer/recovery_teacher
    --model MODEL --seed 611 --devices DEVICES --output NEW_RUN_OUTPUT
The four CONFIG / MODEL / DEVICES combinations are:
  recovery_trajectory_2layers33m / 2layers33m / cuda:0
  recovery_guided_2layers33m / 2layers33m / cuda:0
  recovery_guided_olmo1b / olmo1b / cuda:0
  recovery_guided_mistral7b / mistral7b / cuda:0 cuda:1

Classifier fit:
  experiments/runners/reviewer_recovery_classifier_fit.py
    --config experiments/configs/reviewer/recovery_classifier_fit_2layers33m.json
    --assets /tmp/qft-recovery-search-assets --device cuda:0
    --seed 701 --output NEW_RUN_OUTPUT

Pretrained restarts (the driver constructs a separate bootstrap per seed):
  experiments/runners/run_recovery_guided_restart.py
    --template experiments/configs/reviewer/recovery_guided_2layers33m.json
    --assets /tmp/qft-recovery-search-assets --device cuda:0

Add --large for OLMo or --full-dense for Mistral. For restart attempts use
