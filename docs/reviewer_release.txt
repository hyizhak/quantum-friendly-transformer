untouched final test is claimed. recovery_story_all_attempts.csv discloses all

4(e): release/historical_initial_projection_norms.csv extracts 570 initial
before/after projection pairs for the nine historical bounded models. These are
original recorded norms, not new replays of unavailable historical checkpoints.

516 matrices in the best new run for each of seven models with new attempts.

cap activity is based on the validator's actual learned gamma, not just raw>24.

filter. The 2Layers-33M recovered checkpoint has 12/12 active caps; 33M has 10/24;
1M/3M/8M have no active caps. Mistral dense continuation materializes previously
capped effective weights as its new raw parameters, so its selected raw norms

Reproduction from a fresh directory

Extract the code/results ZIP, then the checkpoint ZIP into the same directory
(the identical manifest is the only overlapping file). Run from that directory.

  python -m venv .venv
  .venv/bin/python -m pip install -e '.[experiments]'
  .venv/bin/python tools/verify_reviewer_records.py

The compact verifier works without installing research dependencies. It resolves
recorded source paths relative to the extracted tree and verifies 92 bounded
and 16 uniform prediction tables, 29 training source files, all 13 fixed-cohort
rows, and the 7/9 distinct-model count. This is record verification, not new
inference. Full prior replay reports are retained separately. Do not edit the
training sources in order to make historical hashes match.

Historical machine paths in manifests are provenance. The original full recovery
auditor expects those paths and is not advertised as relocation-safe; the new
compact verifier is. Runtime package versions are recorded in each manifest.
Full Mistral reproductions also require bitsandbytes (the recorded dense run used
0.50.2), sufficient GPU memory, and omitted parent checkpoints. The small-model
commands below do not require that dependency or those omitted parents.

Repeat a fixed SST-2 cohort into a new output directory:

  .venv/bin/python experiments/runners/prepare_recovery_assets.py \
    --config experiments/configs/reviewer/recovery_extension_low_lr.json \
    --output ./reproduction-assets/sst2
  .venv/bin/python experiments/runners/run_recovery_extension.py \
    --config experiments/configs/reviewer/recovery_extension_low_lr.json \
    --assets ./reproduction-assets/sst2 --output ./reproduced/recovery_low_lr

in experiments/configs/reviewer/RECOVERY_EXTENSION_PROTOCOL.txt. It would run
the complete original cohort plan, including controls canceled in this session;
